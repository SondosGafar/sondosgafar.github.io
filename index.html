Top Project Accepted Research — MIUCC 2026

Dual-Glove Intelligent Agent for Arabic Sign Language

ESP32 · Flex Sensors · IMU · Python · C++ · Machine Learning · Edge TTS

A real-time assistive communication system that translates Arabic sign language into text and speech. Two instrumented gloves capture finger bending and hand motion, stream synchronized sensor data wirelessly to a host machine, and a trained classifier maps the gesture to an Arabic word that is spoken aloud — closing the communication gap between deaf and hearing speakers.

System highlights
  • Dual-glove architecture — two ESP32 microcontrollers, five flex sensors per glove, and MPU6050 IMU sensors for motion and rotation tracking.
  • Signal acquisition — Python and C++ components handling sensor-data acquisition, synchronization, wireless communication, and real-time monitoring.
  • Gesture classification — benchmarked multiple ML models, with gradient boosting delivering the strongest results for words and for letters/numbers.
  • Voice output — Microsoft Edge TTS with Egyptian Arabic pronunciation tuning, selected over XTTS and Chatterbox for lower latency and more natural Egyptian speech.
  • End-to-end integration — hardware, embedded software, machine learning, and speech synthesis combined into one working system.

Dual-Glove Intelligent Agent for Arabic Sign Language Recognition and Speech Translation

6th International Mobile, Intelligent, and Ubiquitous Computing Conference (MIUCC 2026) · 2026

This work presents a wearable dual-glove intelligent agent that recognizes Arabic sign language gestures in real time and converts them into spoken Arabic output. Flex sensors capture finger articulation while IMU sensors track hand motion; the synchronized sensor stream is transmitted wirelessly via ESP32 microcontrollers and classified by machine learning models trained on a labeled gesture dataset. The system achieves 97.95% accuracy for two-hand gesture recognition and 96.41% for letters and numbers, with a text-to-speech layer tuned for natural Egyptian Arabic pronunciation.
