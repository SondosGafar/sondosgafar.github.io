A modern, responsive personal portfolio showcasing my background, technical projects, research, skills, and experience in **Artificial Intelligence, Machine Learning, and Software Engineering**.

## ✨ Features

- **Responsive Design:** Optimized layouts for desktop, tablet, and mobile devices.
- **Light & Dark Modes:** Interactive theme switching using CSS variables and JavaScript.
- **Interactive Navigation:** Fixed navigation bar, smooth scrolling, and mobile menu.
- **Project Showcase:** Featured projects with image galleries, presentations, video demonstrations, documentation, and GitHub links.
- **Professional Overview:** Introduction, academic achievements, and AI specialization.

## 💻 Running Locally

### 1. Clone the Repository

```bash
git clone https://github.com/SondosGafar/sondos-mohamed.github.io.git
```

### 2. Navigate to the Project

```bash
cd sondos-mohamed.github.io
```

### 3. Launch the Website

Open `index.html` in a modern web browser.

No package installation or compilation is required.

Alternatively, serve the project locally using Python:

```bash
python -m http.server 8000
```

Then visit:

http://localhost:8000
